🔧 Google Analytics 4 + Search Console Setup Guide

Admin guide for odiatyping.in — complete step-by-step setup. This page is noindex.

Part 1: Google Search Console

1 Go to Search Console

Visit https://search.google.com/search-console → Click "Start Now" → Sign in with your Google account.

2 Add Your Property

Choose URL prefix method. Enter: https://odiatyping.in/

Click Continue → Choose HTML tag verification method.

3 Get Your Verification Meta Tag

Google will give you a meta tag like:

<meta name="google-site-verification" content="YOUR_CODE_HERE"/>

Copy this and paste it inside the <head> of your index.html, learn.html, and guide.html.

4 Upload & Verify

Upload your updated files to the server → Go back to Search Console → Click Verify. You should see "Ownership verified".

5 Submit Your Sitemap

In Search Console left menu → Sitemaps → Enter: sitemap.xml → Click Submit.

Your sitemap URL is: https://odiatyping.in/sitemap.xml

✅ Your sitemap has 14 URLs. Google will start crawling within 1-7 days.
6 Request Indexing for Key Pages

In Search Console → URL Inspection → Enter each URL → Click "Request Indexing":

  1. https://odiatyping.in/
  2. https://odiatyping.in/learn
  3. https://odiatyping.in/guide
  4. https://odiatyping.in/odia-typing-government-exam

Part 2: Google Analytics 4 (GA4)

1 Create GA4 Property

Visit https://analytics.google.com → Click Start Measuring → Enter account name: Odia Typing Shiksha → Next.

2 Set Up Property

Property name: odiatyping.in → Reporting time zone: India (GMT+5:30) → Currency: Indian Rupee (INR) → Next → Select industry: Education → Create.

3 Get Your Measurement ID

Platform: Web → Enter URL: odiatyping.in → Stream name: Odia Typing Website → Create stream.

Copy your Measurement ID — it looks like: G-XXXXXXXXXX

4 Add Tracking Code to Your Pages

Paste this code inside <head> of ALL your HTML pages (index, learn, guide, about, contact, blog pages, government exam page):

<!-- Google tag (gtag.js) --> <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script> <script> window.dataLayer = window.dataLayer || []; function gtag(){dataLayer.push(arguments);} gtag('js', new Date()); gtag('config', 'G-XXXXXXXXXX'); </script>

Replace G-XXXXXXXXXX with your actual Measurement ID from Step 3.

⚠️ Add this to every page — not just the homepage. Otherwise you won't see traffic from /learn, /guide etc.
5 Verify Tracking is Working

In GA4 → Reports → Realtime → Open your website in another tab → You should see "1 user in last 30 min". If you see this, tracking is working.
